# 古着物販アシスタント（Google Apps Script）

メルカリで古着を販売するときに使っている売上管理スプレッドシート（物販スクール提供）に、
**「今日、定点観測する商品」と「今日、値下げする商品」の色分け**を追加するスクリプトです。

Claude Code と一緒に作りました。開発の流れは記事にまとめています。

## 今使っているもの：`color/Assistant_Color.gs`

商品管理シートの **管理番号と商品名（A〜B列）** に、在庫日数に合わせて自動で色を付けます。

| 色 | 付く日 | 例外 |
| --- | --- | --- |
| 黄色（定点観測） | 出品から 7・14・21・28日目…（7日ごと） | — |
| 赤（値下げ） | 出品から 11・15・19・23日目…（4日ごと） | メモに「値下げ停止」と書いた商品は赤くしない |
| オレンジ | 黄色と赤が重なる日（35・63日目…） | — |

- 売却済み・売却完了・再出品で置き換わった行・無料交換に出した行には色を付けません。
- 色は条件付き書式なので、スクリプトは最初に1回実行するだけです（毎日の処理はありません）。
- もともとある色のルールは消さず、順番も変えません。

### 使い方

1. スプレッドシートの「拡張機能 → Apps Script」を開く
2. 新しいスクリプトファイルを作り、`Assistant_Color.gs` の中身を貼り付けて保存
3. 関数 `asstSetupColors` を選んで「実行」（最初に1回だけ）
4. 色分けをやめるときは `asstRemoveColors` を実行

前提：シートの名前が「商品管理」で、見出しに「管理番号」「在庫日数」「メモ」「売却完了」「再出品済み」「無料交換に出した」の列があること。

## 作ったけど使わなかったもの：`ver1/`

最初に作った多機能版（Ver.1）です。開発用のコピーで動作確認まではしましたが、
1商品ずつ入力する画面が、スプレッドシートに直接コピペするより遅かったため、本番では使っていません。

| ファイル | 内容 |
| --- | --- |
| `Assistant_Config.gs` | 共通の設定（シート名・列名・設定の初期値） |
| `Assistant_Setup.gs` | 導入・初期設定・商品リストの同期 |
| `Assistant_Menu.gs` | 「物販アシスタント」メニュー |
| `Assistant_Observe.gs` | 定点観測の入力画面・ログ・観測まとめ |
| `Assistant_Markdown.gs` | 値下げの入力画面（値下げ回数とメモを自動更新） |
| `Assistant_Tasks.gs` | 今日の物販タスク・毎朝の自動更新・色分け |
| `Assistant_Register.gs` | スクショから商品名と価格を読み取る登録画面（Google ドライブの OCR） |
| `appsscript.json` | 権限の設定（スクショ読み取りのために `drive.file` と `documents` を追加） |

Ver.1 は物販スクールのスプレッドシートとスクリプトの関数を前提にしているので、そのままでは他のシートでは動きません。

## 含めていないもの
